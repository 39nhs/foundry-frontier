# Foundry Frontier

광구의 청크를 해금하며 채굴·재배·가공·운송·판매 자동화 라인을 만드는 탑다운 웹 공장 게임입니다. 플레이어 캐릭터 없이 지도를 이동하며 공장을 직접 설계합니다.

## 게임 목표

31×31 맵의 청크 961개를 모두 해금하면 승리합니다. 승리 화면에서는 완성된 공장을 계속 운영하거나 운영을 종료할 수 있습니다. 보관 전력이 0이 되면 게임 오버입니다.

## 설치 및 실행

필요 환경:

- Node.js 22.13 이상
- pnpm 11.25

```bash
pnpm install
pnpm dev
```

개발 서버 기본 주소는 `http://localhost:5173`입니다.

## 조작법

| 입력 | 기능 |
| --- | --- |
| `W`, `A`, `S`, `D` | 카메라 이동 |
| 마우스 휠 | 지도 확대·축소 |
| 좌클릭 | 건물·벨트 설치 및 선택 확정 |
| 우클릭 | 설비 관리, 벨트 철거, 광맥 직접 채굴, 야생 식물 채집 |
| 터치 드래그 | 카메라 이동 |
| 길게 누르기 | 설비 관리, 채굴, 채집 |
| `Q` | 건설 메뉴 열기·닫기 |
| `E` | 컨베이어 벨트 모드 전환 |
| `F` | 일반·교차·분배·합류 벨트 변경 |

| `Space` | 판매소 열기·닫기 |
| `Esc` | 열린 창 또는 배치 취소 |

## 맵과 자원

- 전체 맵: 31×31청크
- 청크 크기: 15×15타일
- 시작 청크: 광맥 없음, 중앙에 5×5 코어 배치
- 시작 청크 바로 옆: 광맥 1~2개
- 나머지 청크: 광맥 0개 40%, 1개 45%, 2개 15%
- 중심에서 0~5청크: 3티어 광맥과 서리이끼
- 중심에서 6~10청크: 2티어 광맥과 철갈대
- 중심에서 11~15청크: 1티어 광맥과 태양포자
- 야생 식물: 해당 가치 구역에서 청크당 10% 확률로 1×1 크기 생성

야생 식물은 한 번 채집하면 다시 생성되지 않습니다. 기존 저장의 건물과 식물이 겹치면 건물을 우선하고 식물을 제거합니다.

## 생산과 전력

- 1틱은 2초입니다.
- 아이템 생산·입력·출력·벨트 이동은 매 틱 처리합니다.
- 설비가 사용한 전력은 5틱 동안 누적합니다.
- 전력은 5틱, 즉 10초마다 정산합니다.
- 정산식은 `기초 발전 200 + 배터리 발전량 - 누적 설비 소비량`입니다.
- 전기 생성기도 전력 정산 시점마다 배터리를 소비합니다.
- 일반 설비의 아이템별 보관 한도는 50개입니다.

## 건물

| 분류 | 건물 | 역할 |
| --- | --- | --- |
| 채굴 | 채굴기 | 2·3티어 광물을 자동 채굴 |
| 채굴 | 고급 채굴기 | 모든 티어 광물을 자동 채굴 |
| 재배 | 채종기 | 식물 1개를 같은 종류의 씨앗 2개로 변환 |
| 재배 | 재배기 | 씨앗을 식물로 재배 |
| 재배 | 생물 가공기 | 식물 추출·섬유화·효소화·탄화 및 복합 소재 생산 |
| 가공 | 정제기 | 광물 정제 및 미세 정제 |
| 가공 | 분쇄기 | 광물 분쇄 및 미세 분쇄 |
| 가공 | 부품 가공기 | 부품과 식물·광물 복합 제품 생산 |
| 가공 | 합성기 | 배터리와 열제어 모듈 생산 |
| 물류 | 출력기 | 코어의 지정 아이템을 생산 라인으로 출력 |
| 물류 | 입력기 | 운송된 아이템을 코어로 회수 |
| 전력 | 전기 생성기 | 배터리를 보관 전력으로 변환 |

건설 메뉴와 설비 관리 창에서 각 건물의 제작법과 소요 시간을 확인하고 변경할 수 있습니다. 제작법 변경 시 기존 입출력 재고는 코어로 반환됩니다. 설비를 이동할 때는 내부 재고를 유지합니다.

## 컨베이어 벨트

- 일반 벨트: 직선 이동 및 연속 설치 시 ㄱ자 자동 연결
- 교차 벨트: 두 방향의 아이템을 독립적으로 운송
- 분배 벨트: 두 출력 방향을 번갈아 사용하고 막힌 경우 열린 방향으로 우회
- 합류 벨트: 여러 입력을 하나의 출력 방향으로 합류

벨트를 교체하거나 철거하면 운송 중이던 아이템은 코어로 반환됩니다.

## 판매와 저장

판매소에서 판매 가능한 아이템과 수량을 선택해 골드를 얻습니다. 저장 데이터는 브라우저 `localStorage`에 자동 저장되며, 다음 실행 시 이어서 플레이할 수 있습니다.

## 개발자 명령

플레이 중 1.2초 안에 `Enter`를 세 번 누르면 개발자 커맨드 창이 열립니다.

- `give 숫자`: 입력한 수만큼 골드 추가
- `give all`: 등록된 모든 아이템을 코어에 각각 999개 추가

개발자 명령은 기능 확인과 디버깅용입니다.

## 검사 명령

```bash
pnpm test
pnpm lint
pnpm build
```

자동 테스트는 광맥 확률, 식물 가치 구역, 아이템·제작법 연결성, 청크 가격, 5틱 전력 정산 주기, 전체 맵 완료 조건을 확인합니다.
