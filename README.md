# Foundry Frontier

청크를 개척하고 채굴·재배·가공·운송·판매 자동화 라인을 만드는 탑다운 웹 공장 게임입니다.

## 실행

필요 환경은 Node.js 22.13 이상과 pnpm 11.25입니다.

```bash
pnpm install
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

## 검사

```bash
pnpm test
pnpm lint
pnpm build
```

## 조작

- `WASD`: 카메라 이동
- 좌클릭: 건설 및 결정
- 우클릭 또는 길게 누르기: 설비 관리, 광맥 직접 채굴, 야생 식물 채집
- `Q`: 건설 메뉴
- `E`: 컨베이어 벨트 모드
- `F`: 벨트 종류 변경
- `R`: 벨트 방향 회전
- `Space`: 판매소

## 주요 규칙

- 맵은 31×31청크이고 청크 하나는 15×15타일입니다.
- 아이템 생산과 이동은 2초마다 처리합니다.
- 전력은 사용량을 누적해 5틱, 즉 10초마다 정산합니다.
- 961개 청크를 모두 해금하면 승리하며 계속 운영하거나 종료할 수 있습니다.
- 저장 데이터는 브라우저 `localStorage`에 자동 저장됩니다.
