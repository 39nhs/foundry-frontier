# Foundry Frontier 게임 기획서

## 핵심 콘셉트

광활한 4번 광구에서 청크를 해금하고, 채굴·가공·운송·판매 자동화 라인을 확장하는 탑다운 웹 공장 타이쿤입니다. 기존 작품의 고유 명칭과 리소스는 사용하지 않고 자체 세계관과 디자인으로 구성합니다.

## 확정 규칙

- 플레이어 캐릭터 없이 `WASD`로 카메라를 이동합니다.
- 좌클릭은 건설·결정, 우클릭은 건물 관리 또는 광맥 직접 채굴입니다.
- `Q`는 건물 메뉴, `E`는 컨베이어 벨트 모드, `Space`는 판매소를 열고 닫습니다. 벨트 모드에서는 `F`로 종류를 바꾸고 `R`로 방향을 회전합니다.
- PLAYING 상태에서 1.2초 안에 `Enter`를 세 번 누르면 개발자 커맨드 창이 열립니다. `give 숫자`는 입력한 수만큼 골드를 추가하며 최대 999,999,999 G로 제한되고, `give all`은 등록된 모든 아이템을 코어에 각각 999개씩 추가합니다.
- 최초 15×15 청크에서 시작하며 코어는 이 최초 청크의 중앙에 배치됩니다. 전체 맵은 31×31청크, 청크 하나는 15×15타일입니다.
- 중앙에서 0~5청크는 3티어, 6~10청크는 2티어, 11~15청크는 1티어 광맥이 생성됩니다. 숫자가 작을수록 희귀하고 가치가 높습니다.
- 청크 가격은 첫 구매 500골드이며 `500 × 구매 순번 × log₂(구매 순번+1)`로 증가합니다.
- 광맥은 3×3타일이며, 채굴기 프리뷰가 광맥에 닿으면 정확한 위치로 자동 정렬됩니다.
- 시작 청크에는 광맥이 없고, 시작 청크에 바로 인접한 네 청크에는 기존 규칙대로 광맥이 1~2개 생성됩니다. 그 밖의 청크는 광맥 0개 40%, 1개 45%, 2개 15% 확률을 적용합니다.
- 1틱은 2초입니다. 아이템 이동과 생산은 매 틱 처리하고, 설비 전력 사용량은 5틱 동안 누적한 뒤 10초마다 `기초 생산 200 + 배터리 발전량 - 누적 설비 소비량`으로 보관 전력을 정산합니다. 전기 생성기도 이 정산 시점마다 배터리를 사용합니다.
- 코어는 5×5이며 입력·출력 포트가 각각 6개입니다. 일반 건물은 3×3이며 왼쪽 입력 포트 3개와 오른쪽 출력 포트 3개를 사용합니다. 채굴기와 고급 채굴기는 별도 입·출력 포트 없이 채굴물을 10초마다 코어로 자동 전송합니다.
- 아이템은 `건물 출력 → 벨트/건물 입력` 또는 `벨트 출력 방향 → 벨트/건물 입력`으로만 이동합니다. 포트가 아닌 면에는 연결되지 않습니다. 벨트를 인접 타일에 연속 설치하면 직전 벨트가 새 타일 방향으로 자동 회전하며 ㄱ자 구간으로 표시됩니다.
- 건물 포트에서 벨트 드래그를 시작하면 바깥쪽 인접 칸으로 자동 스냅됩니다. 출력 포트에서 바깥쪽으로 그린 경로는 흐름 방향을 유지하고, 입력 포트에서 바깥쪽으로 그린 경로는 방향을 뒤집어 건물 쪽으로 유입되게 연결합니다. 입력 포트 옆에서 끝난 경로도 마지막 벨트 방향을 포트 쪽으로 자동 보정합니다.
- 벨트 드래그 중에는 경로 미리보기만 표시합니다. 마우스나 손가락을 놓았을 때 1~4칸 경로는 바로 설치하고, 5칸 이상 경로는 체크/× 확인을 받은 뒤 한 번에 설치하거나 취소합니다.
- 벨트 모드에서 PC 우클릭 드래그 또는 `삭제 선택` 모드의 마우스·터치 드래그로 여러 벨트를 철거 대상으로 선택합니다. 1~4칸은 드래그 종료 시 바로 철거하고, 5칸 이상은 체크/× 확인 후 일괄 철거하거나 취소하며 운송 중인 아이템은 코어로 반환합니다.
- 교차 벨트는 지정 방향과 그 시계 방향의 두 독립 통로를 가지며, 서로 다른 아이템 2개가 충돌 없이 동시에 지나갈 수 있습니다.
- 분배 벨트는 지정 방향과 시계 방향 출구를 번갈아 선택합니다. 선택한 출구가 막혀 있으면 열린 출구로 우회합니다.
- 합류 벨트는 여러 방향에서 들어오는 아이템을 한 칸 버퍼로 받아 지정 방향의 단일 출력으로 보냅니다.
- 벨트 교체 또는 철거 시 운송 중이던 아이템은 코어 재고로 반환됩니다.
- 일반 건물의 아이템별 보관 한도는 50개입니다.
- 설비 관리창에서 현재 제작법에 필요한 재료를 코어에서 입력 보관함으로 직접 넣을 수 있으며, 입력·출력 보관함의 아이템은 1개·10개·전량 단위로 코어에 직접 회수할 수 있습니다.
- 채굴기는 5틱마다 채굴물을 코어로 자동 전송합니다. 고급 채굴기도 같은 규칙을 적용합니다.
- 레시피와 아이템 정의는 코드에서 분리하여 수정할 수 있게 관리합니다.

## 시작 자원

- 골드 1,000
- 기초 전력 생산 틱당 200
- 전력 저장량 및 한도 10,000
- 중앙 코어 1개
- 태양포자·철갈대·서리이끼 씨앗 각 2개

## 재배 및 복합 제조

광물만 순서대로 가공하던 기존 생산망에 순환형 재배와 교차 제조를 추가합니다. 식물과 설비 명칭은 Foundry Frontier의 자체 설정을 사용합니다.

- 야생 식물은 광물 가치 구역과 같은 거리 등급을 따릅니다. 중심 0~5청크에는 기초 식물인 서리이끼, 중거리 6~10청크에는 철갈대, 외곽 11~15청크에는 고가 생산망용 태양포자가 해당 구역의 청크마다 10% 확률로 1×1 타일에 생성됩니다. 해금한 청크의 야생 식물을 우클릭하거나 길게 눌러 채집하면 식물 1개가 코어에 들어가며, 채집한 자리에는 다시 생성되지 않습니다.
- `채종기`: 식물 1개를 같은 종류의 씨앗 2개로 바꿉니다.
- `재배기`: 씨앗 1개를 3틱 동안 재배해 식물 1개로 바꿉니다.
- `생물 가공기`: 식물을 추출물·섬유·효소 또는 바이오 탄소로 가공하고, 두 종류의 식물 가공물을 영양 젤·절연 수지·촉매 펄프로 합성합니다.
- `부품 가공기`: 식물 가공물과 광물 가공물을 함께 사용해 산업 폭약·회로 코팅제·복합 장갑판을 만들며, 정제된 1티어 광물과 분쇄된 2티어 광물로 정밀 기어를 만듭니다.
- `합성기`: 바이오 탄소·영양 젤·산업 폭약으로 바이오 하이브리드 전지를 만들고, 정밀 기어·곱게 분쇄된 2티어 광물·절연 수지로 열제어 모듈을 만듭니다.
- `전기 생성기`: 기존 전지 3종에 더해 바이오 하이브리드 전지를 우선 사용하며 3,500 전력을 생산합니다.
- 제작법마다 1~3틱의 처리 시간이 있으며 건설 카탈로그와 설비 관리 창에서 초 단위로 확인할 수 있습니다.

재배의 기본 순환은 `식물 → 씨앗 2개 → 식물 2개`입니다. 생산된 식물 일부를 다시 채종기에 보내고 나머지를 생물 가공기로 보내면 외부 채집 없이 라인이 유지됩니다. 전체 제조법은 36개이며, 재배 산출물은 기존 광물 체인과 결합되어 고가 제품 및 발전 연료로 이어집니다. 기존에 후속 사용처가 없던 정제된 1티어 광물·분쇄된 2티어 광물·곱게 분쇄된 2티어 광물은 정밀 기어와 열제어 모듈 생산에 사용됩니다.

## 의도 및 보류 사항

- 설비 입력칸이 현재 제작법에 필요하지 않은 재료도 받는 동작은 의도 사항이며 변경하지 않습니다. 잘못 넣은 재료는 설비 관리 창에서 코어로 회수할 수 있습니다.
- 광맥 직접 채굴은 별도 제한 없이 유지하며 추가 개발하지 않습니다.
- 시작 시 씨앗 3종을 지급하여 야생 식물 탐험의 필요성이 낮아지는 점은 현재 상태로 보관하고 수정할 계획이 없습니다.
- 기존 저장에 설치된 건물과 새 야생 식물이 겹치면 건물을 우선하고 해당 식물은 제거합니다.

## 승리 조건

31×31 맵의 961개 청크를 모두 해금하면 전체 광구 개척 완료 화면이 표시됩니다. 플레이어는 완성한 공장을 계속 자유 운영하거나 운영을 종료할 수 있습니다.

## 완성 기준

31×31 청크 경계, 청크 구매, 전체 개척 승리 조건, 티어별 광맥, 모든 건물, 레시피 변경, 5틱 전력 정산과 전력 정지, 벨트 운송, 코어 입출력, 판매 스테이지, 저장 및 이어하기, 개발자 커맨드가 브라우저에서 동작해야 합니다.
